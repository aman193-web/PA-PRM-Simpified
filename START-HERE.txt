PRM Partner Portal — local project snapshot, October 21, 2026

Extract the ZIP, open a terminal in PA-PRM, and run:
  python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
Then open http://localhost:4173/

No build step or npm install is required. The editable app is in dist/.
Both portals use browser-local demo authentication and simulated Salesforce.
Roles: Partner Manager and Partner Account Manager.
Users & permissions stores local demo settings; no live accounts are provisioned.
Browser refresh restores seeded lead/deal journeys to their initial positions.
Independently created records remain saved in that browser. Data from the author's
browser is not included in this ZIP.

Run automated checks with Node.js:
  node --test tests/*.test.cjs

This snapshot includes the current local changes, UI layout fixes, user directory,
and sample-refresh behavior. No deployment was performed to create this ZIP.
